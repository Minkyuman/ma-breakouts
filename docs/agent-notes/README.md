# Agent notes — LINE BREAKER

`docs/agent-notes/` is a tracked project knowledge directory. It is ordinary Markdown, not an automatically loaded Codex surface. `AGENTS.md` indicates when each note is relevant.

## Index

- [project-state.md](project-state.md) — read at the start of a resumed or handoff session.
- [self-check.md](self-check.md) — read before selecting validation commands.
- [workflows.md](workflows.md) — read for recurring application, database, and deployment work.

## Maintenance

Code, migrations, environment configuration, and the root [README](../../README.md) are authoritative over these notes. Update a note only when its durable knowledge changes within the current task scope; do not record secrets or copy environment values into it.
